1. Quick Start Guide

Required

Follow these essential steps to get started with SpectrAnalys. These steps are required to load and visualize your spectra.

1 Upload Spectra Files Required ▼

Upload one or more .txt files containing spectroscopic data.

  • File format: Two columns separated by tabs (Tab) or any whitespace
  • Column 1: X‑axis values (e.g., Raman shift in cm⁻¹)
  • Column 2: Y‑axis values (e.g., Intensity in a.u.)
💡 Note: Files must be in .txt format with the structure shown below: 
100.5    1250.3
101.2    1248.7
102.0    1251.5
...
ℹ️ How loading works: the parser uses pandas.read_csv(sep='\s+', header=None). Columns beyond the 2nd are ignored. Rows with NaN, inf, or -inf are dropped. X‑values are sorted ascending automatically. If your file uses a comma as the decimal separator, convert it before upload.
2 Select Spectra for Display Required ▼

In the sidebar, under "📋 Spectrum Selection", check the boxes next to the spectra you want to visualize.

  • Multi‑select: Choose any combination of spectra
  • Ordering: Spectra appear in the order they are selected — this defines the offset stacking and the gradient color order
  • Colors: Each spectrum is automatically assigned a unique color from a 15-color palette
💡 Tip: For large datasets, select only the spectra you need to keep the plot clean and focused. Deselected spectra do not participate in any calculation (heatmaps, 3D, correlation).
3 Assign Colors to Spectra Required ▼

Scroll to the bottom of the sidebar to the "🎨 Color Assignment" section.

  • Each spectrum has a color picker
  • Click the color box to open the color palette
  • Choose any color to distinguish your spectra
  • Colors update in real‑time across all tabs and all exports
💡 Note: Consistent color coding helps identify spectra across different visualization modes. Colors are stored in cached_spectra_data['spectra_data'][name]['color'].
4 Configure Axis Labels, Preprocessing & Normalization Required ▼

Under "⚙️ Processing Options", set up axis labels and, if needed, enable preprocessing and normalization.

  • X‑axis label: Typically Raman shift (cm⁻¹)
  • Y‑axis label: Typically Intensity (a.u.)
  • Preprocessing (new): Optional despike, denoise, and baseline correction — applied automatically before normalization. See Section 8.
  • Normalization: Choose from Maximum intensity, Peak intensity (range), or Maximum rest intensity
💡 Tip: If the spectra have strong fluorescence background, enable Baseline correction with the Raman preset before normalization.
5 Set Offset & Fill Options Required ▼

Adjust visual parameters for clear spectral comparison.

  • Raw offset step: Vertical spacing between raw spectra (0–50000, typical 1000–5000)
  • Normalized offset step: Vertical spacing between normalized spectra (0–5, typical 0.2–1.0)
  • Fill area: Toggle to fill the area under normalized spectra curves
  • Fill transparency: Adjust opacity (0.2 = transparent, 0.9 = opaque)
  • Subtract minimum: Force all spectra to start from zero baseline
💡 Note: Offset values are cumulative: 1st spectrum at 0×step, 2nd at 1×step, 3rd at 2×step, etc.
6 Apply & Visualize Required ▼

All settings are applied automatically. Navigate to the "Combined Spectra Visualization" tab.

  • 4 visualization modes: Raw, Normalized, Raw+Offset, Normalized+Offset
  • Interactive plots: Hover to see values, zoom and pan using the toolbar
  • Download: Click "📥 Download Plot N" below each plot for high‑resolution PNG (600 dpi)
💡 Tip: Top navigation pills give access to all tabs: Combined, Peak Analysis, Voigt Fitting, Correlation, Compare, Markers, 3D Graphs, Heatmaps.

🔀 What "global" means in practice Info ▼
  • Single source of truth: All parameters live in st.session_state and are copied into cached_spectra_data on every interaction.

  • Colors: The current color for each spectrum is used by all plots, heatmaps (for 3D line plots), and exported PNGs.

4. Data Pipeline & Caching

Info

Understanding the order of operations helps predict what changes when. This section also explains why some tabs are fast and some slow.

1 Order of operations Info ▼
Upload→load_spectrum (cached)
Preprocessing→despike → denoise → baseline (cached per x,y,params)
Align→align_x_ranges (if common_x_range enabled)
Normalize→normalize_spectrum (cached per x,y,method,range)
Visualize / Analyze→per-tab render functions
⚠️ Important: Preprocessing is applied before alignment and normalization. This is intentional — baseline correction needs the original x‑grid.
2 Caching — what gets cached Info ▼
  • load_spectrum — per uploaded file.
  • preprocess_spectra_cached — per (x bytes, y bytes, params).
  • normalize_spectrum — per (x, y, method, range).
  • align_x_ranges — per spectra_dict.
  • prepare_heatmap_data_cached, prepare_marker_spectra, prepare_3d_data — per relevant inputs.
3 Cache invalidation Info ▼
  • Changing preprocessing params invalidates only preprocessing cache.
  • Changing normalization method invalidates normalization cache.
  • Changing colors does not invalidate any numeric cache.
  • Adding/removing spectra invalidates everything downstream.
4 Fragment isolation Info ▼
  • Each tab is wrapped in @st.fragment — slider changes within a tab re‑render only that tab.
  • Global sidebar changes still re‑render everything (they affect all data).
  • This is why Marker editing feels snappy while global preprocessing is heavier.

6. Normalization

Optional

Normalization corrects intensity variations and enables meaningful comparison between spectra.

1 Maximum Intensity Optional ▼
  • Scales each spectrum so its maximum intensity = 1.0.
  • Use case: general comparison where the highest peak is consistent.
  • Limitation: can be affected by noise or outliers.
2 Peak Intensity (Range) Optional ▼
  • Scales by the max intensity within a user‑specified X‑range.
  • Example: 800-1000 for a carbon peak.
  • Enter range as start-end in the Peak range for normalization field.
  • If the range is invalid or empty, falls back to global maximum.
3 Maximum Rest Intensity Optional ▼
  • Normalizes using the max intensity in specified rest ranges (regions without peaks).
  • Only available when Custom ranges (multiple) is selected.
  • Uses the same ranges as the display crop.
⚠️ Important: If rest ranges are empty or contain no data, normalization falls back to global maximum.

8. Preprocessing

New

Preprocessing is a global layer applied to all spectra before normalization and before any visualization or analysis. All changes are applied automatically as you adjust parameters — no Apply button is required.

1 Where to find it New ▼

In the sidebar, under "⚙️ Processing Options", expand the 🧹 Preprocessing section. It contains three independent blocks: Despike, Denoise, and Baseline correction.

💡 Note: Each block has its own enable checkbox. If all are disabled, spectra pass through unchanged.
2 Despike (Whitaker–Hayes) New ▼
  • Kernel size — 1–15, neighborhood for local median.
  • Threshold — 1.0–30.0, modified z‑score threshold.
  • Function: despike_whitaker_hayes.
💡 Tip: defaults (kernel 3, threshold 8) work well for most Raman data. Increase threshold to 10–12 if real peaks are altered.
3 Denoise New ▼
  • SavGol — window_length 3–51 odd, polyorder 1–7. Default: 9 / 3.
  • Gaussian — sigma 0.1–10. Default: 1.0.
  • Whittaker — lambda 1–1e10. Default: 1e3.
  • Kernel — kernel_type flat/hanning/hamming/bartlett/blackman, kernel_size 3–51 odd. Default: hanning / 11.
⚠️ Warning: too large a window or sigma will broaden and flatten real peaks.
4 Baseline Correction (14 methods) New ▼

Penalized least‑squares family (recommended for Raman): AsLS, IAsLS, airPLS, arPLS, drPLS, IarPLS, asPLS.

Polynomial family: Poly, ModPoly, IModPoly, Goldindec.

Spline / classification: IRSQR, CornerCutting, FABC.

Presets:

  • Raman — lam=1e5, p=1e-2, diff_order=2 (default).
  • Fluorescence — lam=1e6, p=1e-3, diff_order=2.
  • Polynomial — poly_order=3.
  • Aggressive — lam=1e7, p=1e-4, diff_order=3.

Manual parameters: lambda, p, diff_order, poly_order, max_iter, tol.

💡 Tip: start with Raman preset + asPLS. If residual background remains, increase lambda ×10 and/or decrease p ÷10.
5 Show removed baseline (diagnostics) New ▼
  • Enable "Show removed baseline on plots" to overlay the subtracted baseline on the Combined tab.
  • Drawn as dotted line in the spectrum's color, only on raw plots.
  • Purely diagnostic — does not affect computations.
6 Pipeline order and dependencies New ▼
  1. Raw data loaded
  2. Despike (if enabled)
  3. Denoise (if enabled)
  4. Baseline correction (if enabled)
  5. Align X ranges (if enabled)
  6. Normalization
  7. Visualization / analysis
⚠️ Requires: pybaselines (pip install pybaselines). Despike and denoise use only scipy.

9. Voigt Fitting

New

Decompose a single spectrum into individual peak components using Voigt, PseudoVoigt, Gaussian, or Lorentzian profiles. Each spectrum is fit individually, not in batch.

1 Select spectrum and data mode New ▼
  • Select spectrum to fit — dropdown with all loaded spectra.
  • Data mode — Raw (after preprocessing) / Normalized (global norm_method).
💡 Note: Preprocessing is always applied. The mode only controls whether normalization is applied on top.
2 Configure fit parameters (draft state) New ▼

Changing any parameter does not trigger computation — values are stored in voigt_fit_draft.

  • Profile type — Voigt / PseudoVoigt / Gaussian / Lorentzian.
  • Peak detection threshold — minimum peak height for initial detection.
  • Minimum peak height — peaks below this are removed after each iteration.
  • Min distance between peaks — points.
  • Prominence — 0 = auto; increase to skip broad shoulders.
  • Center variation (±) — how much a peak center may shift during fit.
  • Max residual-add iterations — 0–20.
  • Reduce data points factor — 0 = no reduction; >1 speeds up fitting.
  • Fit method — leastsq (fast, default) / least_squares (robust) / nelder.
3 Fit range and baseline component New ▼
  • Use global x_ranges from sidebar — reuses the sidebar ranges.
  • Otherwise local sliders: Fit range: left and Fit range: right.
  • Add baseline component to model — Constant / Linear / Polynomial (order 1–10).
4 Apply Fit / Clear Result New ▼
  • 🚀 Apply Fit — runs the fit for the selected spectrum; a progress bar shows residual iterations.
  • 🗑️ Clear Result — removes stored result without changing parameters.
  • Result stored in voigt_fit_result and tagged with voigt_fit_result_for = (spectrum_name, mode).
⚠️ Note: Changing the spectrum or mode after fitting keeps the old result visible with a notice. Press Apply Fit again to recompute, or Clear Result to reset.
5 Interpret results New ▼
  • Plot: data, total fit (dashed red), components, baseline (dotted gray), residuals.
  • Component table: Center (± error), Height (± error), FWHM (± error), Area (± error), Sigma, Gamma, Lorentz_frac.
  • Quality metrics: reduced χ², χ², R², AIC, BIC, N points, varying parameters, DOF, fit range.
  • Fit log expander: full lmfit report (if Verbose enabled).
6 Export New ▼
  • 📥 Download Components (CSV) — full table with parameters and errors.
  • 📥 Download Fit Plot (PNG, 600 dpi) — publication‑ready figure.
⚠️ Requires: lmfit (pip install lmfit).

11. Parameter Correlation

Advanced

Correlate spectral features (Intensity, Area, Position, FWHM) with experimental parameters.

  • Checkbox: Enable correlation analysis.
  • One number_input per spectrum (parameter value).
  • Parameter label text input (e.g., "Temperature (°C)").

18. Session State & Troubleshooting

Help

What survives a rerun, what resets, and how to solve common issues.

🔄 Session state — what is preserved Info ▼
  • Preserved across reruns: uploaded file references, selected spectra, colors, preprocessing params, normalization, offsets, plot settings, peak results, correlation params, compare selections, markers, 3D params, heatmap params, Voigt draft and result.
  • Reset by "🗑️ Remove all spectra": everything except uploader_key.
  • Reset by page refresh: only UI widget state that Streamlit does not persist by default; all st.session_state entries persist within the browser session.
🧾 Common issues Info ▼
IssuePossible CauseSolution
No spectra appearFiles not selected or incorrectly formattedCheck 2‑column whitespace‑separated format. Ensure spectra are selected in sidebar.
Peak analysis finds no peaksRange too narrow or peaks below thresholdWiden the range or adjust peak width.
Heatmap shows no dataValues not assigned or Apply not clickedAssign parameter values and click Apply for heatmaps.
Normalized spectra look identicalAll spectra have same maximumUse "Peak intensity (range)" or "Maximum rest intensity".
File uploader not clearingSession state not fully resetClick 🗑️ Remove all spectra.
Correlation shows NaNInsufficient points or no peaks includedNeed ≥3 spectra with included peaks.
Markers not showingShow X values / Show preview disabledEnable both in the Markers tab.
Plots not updatingBrowser cacheRefresh page (F5). Session state is preserved.
Baseline removes real peakslambda too high or p too lowLower lambda ×10 and/or increase p (try 1e-1). Use Raman preset. Enable "Show removed baseline".
Baseline leaves residual backgroundlambda too low or p too highIncrease lambda ×10 and/or lower p (try 1e-3). Try Aggressive preset.
Denoise distorts peak shapesWindow/sigma too largeReduce window_length or sigma. Prefer SavGol polyorder 2–3, window 7–11.
Voigt fit finds too many componentsMin height too low or iterations too highIncrease Minimum peak height, reduce Max residual‑add iterations, or enable a baseline component.
Voigt fit finds too few componentsThreshold too highLower Peak detection threshold / Minimum peak height, increase Max iterations.
Voigt fit does not converge / very slowToo many peaks, noisy data, or too many pointsSet Reduce data points factor (2–5), use least_squares, reduce Max iterations, or narrow the fit range.
ModuleNotFoundError: pybaselines / lmfitDependencies not installedpip install pybaselines lmfit and restart Streamlit.
Voigt Fitting shows old resultResult belongs to a different spectrum/modeClick Clear Result or press Apply Fit again.
Sidebar parameter change is slowBaseline correction is heavyDisable baseline temporarily, or switch to a lighter method (AsLS, airPLS).
Legend overlaps curvesSmall plot + many spectraIncrease Legend offset or reduce Legend font size.
Export CSV emptyNo spectra selectedSelect at least one spectrum in the sidebar.
Logo/instruction missingFiles not in root folderPlace logo.png and instruction.html next to the script.
💡 General Tips Help ▼
  • Start simple: 2–3 spectra to understand the workflow.
  • Preprocessing first: baseline correction before Voigt fitting.
  • Naming conventions: numeric filenames enable auto‑extraction.
  • Save frequently: export CSV + Session Info + PNG.
  • Reset if stuck: 🗑️ Remove all spectra.
  • Diagnose baseline: enable "Show removed baseline".
  • Use tooltips: hover sliders/inputs for inline help.
  • Keyboard: Esc collapses all open sections.
