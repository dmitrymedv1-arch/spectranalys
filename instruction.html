1. Quick Start Guide

Required

Follow these essential steps to get started with SpectrAnalys. These steps are required to load and visualize your spectra.

1 Upload Spectra Files Required ▼

Upload one or more .txt files containing spectroscopic data.

  • File format: Two columns separated by tabs (Tab)
  • Column 1: X‑axis values (e.g., Raman shift in cm⁻¹)
  • Column 2: Y‑axis values (e.g., Intensity in a.u.)
💡 Note: Files must be in .txt format with the structure shown below: 
100.5    1250.3
101.2    1248.7
102.0    1251.5
...
2 Select Spectra for Display Required ▼

In the sidebar, under "Spectrum Selection", check the boxes next to the spectra you want to visualize.

  • Multi‑select: Choose any combination of spectra
  • Ordering: Spectra appear in the order they are selected
  • Colors: Each spectrum is automatically assigned a unique color (customizable later)
💡 Tip: For large datasets, select only the spectra you need to keep the plot clean and focused.
3 Assign Colors to Spectra Required ▼

Scroll to the bottom of the sidebar to the "Color Assignment" section.

  • Each spectrum has a color picker
  • Click the color box to open the color palette
  • Choose any color to distinguish your spectra
  • Colors update in real‑time across all tabs
💡 Note: Consistent color coding helps identify spectra across different visualization modes.
4 Configure Axis Labels, Preprocessing & Normalization Required ▼

Under "Processing Options", set up axis labels and, if needed, enable preprocessing and normalization.

  • X‑axis label: Typically Raman shift (cm⁻¹)
  • Y‑axis label: Typically Intensity (a.u.)
  • Preprocessing (new): Optional despike, denoise, and baseline correction — applied automatically before normalization. See Section 5.
  • Normalization: Choose from Maximum intensity, Peak intensity (range), or Maximum rest intensity
💡 Tip: If the spectra have strong fluorescence background, enable Baseline correction with the Raman preset before normalization.
5 Set Offset & Fill Options Required ▼

Adjust visual parameters for clear spectral comparison.

  • Raw offset step: Vertical spacing between raw spectra (typical: 1000–5000)
  • Normalized offset step: Vertical spacing between normalized spectra (typical: 0.2–1.0)
  • Fill area: Toggle to fill the area under normalized spectra curves
  • Fill transparency: Adjust opacity (0.2 = transparent, 0.9 = opaque)
  • Subtract minimum: Force all spectra to start from zero baseline
💡 Note: Offset values are cumulative: 1st spectrum at 0×step, 2nd at 1×step, 3rd at 2×step, etc.
6 Apply & Visualize Required ▼

All settings are applied automatically. Navigate to the "Combined Spectra Visualization" tab.

  • 4 visualization modes: Raw, Normalized, Raw+Offset, Normalized+Offset
  • Interactive plots: Hover to see values, zoom and pan using the toolbar
  • Download: Click "Download Plot" below each plot for high‑resolution PNG (600 dpi)
💡 Tip: New tabs Preprocessing and Voigt Fitting are available in the top navigation. See Sections 5 and 6.

Required

SpectrAnalys offers four complementary visualization modes to examine your data from different perspectives.

📈

Raw Spectra

Original intensity values (after preprocessing, if enabled). Best for checking raw data quality.

📊

Customize plot appearance to suit your presentation needs.

  • Legend font size: Adjust from 4 to 16 points
  • Legend position: Right, Best, Upper/Lower corners

  • Grid: Toggle scientific grid lines on/off

Automatically assign colors to all spectra using a gradient palette.

  • Select a palette (Reds_r, RdBu_r, turbo, Spectral, viridis, plasma, etc.)
  • Click "Apply gradient colors" to assign colors based on the ordering of spectra
  • Individual colors can still be fine‑tuned afterwards in the Color Assignment section
💡 Tip: Gradient palettes are excellent for temperature or concentration series where sequential coloring makes trends visible.

3. Normalization

Optional

Normalization corrects intensity variations and enables meaningful comparison between spectra.

1 Maximum Intensity Optional ▼

Scales each spectrum so its maximum intensity equals 1.0.

  • Use case: General comparison where the highest peak is consistent across samples
  • Advantage: Simple and fast
  • Limitation: Can be affected by noise or outliers
💡 Tip: This is the default method and works well for most applications.
2 Peak Intensity (Range) Optional ▼

Scales spectra by the maximum intensity within a user‑specified X‑range.

  • Use case: When you have a reference peak (e.g., a known Raman band)
  • Example: 800-1000 for a carbon peak
  • Advantage: More consistent than global maximum
💡 Note: Enter the range as start-end (e.g., 800-1000). Values are in X‑axis units.
3 Maximum Rest Intensity Optional ▼

Normalizes using the maximum intensity within specified rest ranges (regions without peaks).

  • Use case: When you want to normalize by background or baseline regions
  • Example: 100-200, 500-600, 1200-1300
  • Advantage: Removes influence of large peaks
⚠️ Important: This option is only available when "Custom ranges (multiple)" is selected for X‑axis.

4. X‑Axis Ranges (Broken Axis)

Optional

Display multiple X‑axis ranges on the same plot with gaps between them — useful for highlighting specific regions.

1 Select Range Mode Optional ▼

Under "Processing Options" → "X‑axis Ranges", choose:

  • Full range: Displays the entire spectrum
  • Custom ranges (multiple): Displays only the specified ranges
2 Define Custom Ranges Optional ▼

Enter ranges in the text area using the format:

  • Single range: 100-200
  • Multiple ranges: 100-200, 350-450, 600-800
  • Separate ranges with commas
  • Use spaces for readability (e.g., 100-200, 350-450)
💡 Note: Ranges are automatically validated. Invalid ranges are ignored.
3 Visualization Optional ▼

When using custom ranges:

  • Each range is displayed as a separate segment
  • Dashed vertical lines mark range boundaries
  • Gaps between ranges are automatically inserted
  • All normalization methods work with ranges
💡 Tip: Use this feature to zoom in on specific peaks while maintaining context.

5. Preprocessing (New)

New

Preprocessing is a global layer applied to all spectra before normalization and before any visualization or analysis. All changes are applied automatically as you adjust parameters — no Apply button is required.

1 Where to find it New ▼

In the sidebar, under "Processing Options", expand the 🧹 Preprocessing section. It contains three independent blocks:

  • Despike (Whitaker–Hayes) — removes cosmic-ray spikes
  • Denoise — SavGol / Gaussian / Whittaker / Kernel smoothing
  • Baseline correction — 14 methods from pybaselines
💡 Note: Each block has its own enable checkbox. If all are disabled, spectra pass through unchanged (identical to the old behavior).
2 Despike (Whitaker–Hayes) New ▼

Removes narrow spikes (cosmic rays) without affecting real peaks.

  • Kernel size: 1–15 — neighborhood size for the local median
  • Threshold: 1.0–30.0 — modified z-score threshold (higher = less aggressive)
💡 Tip: Start with defaults (kernel 3, threshold 8). If real peaks are being altered, increase the threshold to 10–12.
3 Denoise New ▼

Smoothing to reduce random noise. Choose one method:

  • SavGol: Polynomial smoothing. Parameters: window_length (odd, 3–51), polyorder (1–7). Best general-purpose choice.
  • Gaussian: Gaussian blur. Parameter: sigma (0.1–10). Best for very noisy spectra.
  • Whittaker: Penalized least squares. Parameter: lambda (1–1e10). Best for preserving peak shape.
  • Kernel: Moving average with flat/hanning/hamming/bartlett/blackman window. Parameters: kernel_type, kernel_size (odd, 3–51).
⚠️ Warning: Too large a window or sigma will broaden and flatten real peaks. Reduce if peak shapes look distorted.
4 Baseline Correction (14 methods) New ▼

Removes fluorescence background and slow baseline drift. Powered by pybaselines.

Available methods:

  • AsLS, IAsLS, airPLS, arPLS, drPLS, IarPLS, asPLS — penalized least-squares family (best for Raman)
  • Poly, ModPoly, IModPoly, Goldindec — polynomial fitting
  • IRSQR, CornerCutting, FABC — spline / classification based

Presets (fill in lambda/p/diff_order/poly_order):

  • Raman — lam=1e5, p=1e-2, diff_order=2 (default, best for typical Raman)
  • Fluorescence — lam=1e6, p=1e-3, diff_order=2 (stronger background)
  • Polynomial — poly_order=3 (smooth broad background)
  • Aggressive — lam=1e7, p=1e-4, diff_order=3 (very strong correction)

Manual parameters:

  • lambda — smoothness (higher = smoother baseline)
  • p — asymmetry (smaller = baseline stays below peaks)
  • diff_order — derivative order (2 or 3)
  • poly_order — polynomial degree for Poly-family
  • max_iter, tol — iteration limits
💡 Tip: Start with the Raman preset and asPLS. If residual background remains, increase lambda by 10× and/or decrease p by 10×.
5 Show removed baseline (diagnostics) New ▼

Enable "Show removed baseline on plots" to overlay the subtracted baseline on the Combined Spectra Visualization tab.

  • Baseline is drawn as a dotted line in the spectrum's color
  • Only shown on the raw plots (not normalized)
  • Purely diagnostic — does not affect computations
6 Pipeline order and dependencies New ▼

Order of operations:

  1. Raw data loaded
  2. Despike (if enabled)
  3. Denoise (if enabled)
  4. Baseline correction (if enabled)
  5. Align X ranges (if "Align all spectra to common x range" is checked)
  6. Normalization (see Section 3)
  7. Visualization / analysis
💡 Note: Preprocessing is applied before normalization and before alignment. This ensures baseline correction sees the original x‑grid.
⚠️ Requires: pybaselines (install via pip install pybaselines). Despike and denoise use only scipy, which is already a dependency.

6. Voigt Fitting (New)

New

Decompose a single spectrum into individual peak components using Voigt, PseudoVoigt, Gaussian, or Lorentzian profiles. This is the full fitting module — each spectrum is fit individually, not in batch.

1 Select spectrum and data mode New ▼

Open the "Voigt Fitting" tab from the top navigation.

  • Select spectrum to fit: dropdown with all loaded spectra
  • Data mode:
    • Raw (after preprocessing) — uses y after preprocessing, without normalization
    • Normalized (global norm_method) — uses the global normalization from the sidebar
💡 Note: Preprocessing is always applied (it is a global layer). The mode only controls whether normalize_spectrum is applied on top.
2 Configure fit parameters (no computation yet) New ▼

Changing any parameter does not trigger computation — values are only stored in a draft state.

  • Profile type: Voigt (default, most physical) / PseudoVoigt (faster) / Gaussian / Lorentzian
  • Peak detection threshold: minimum peak height for initial detection
  • Minimum peak height: peaks with lower height are removed after each iteration
  • Min distance between peaks: minimum distance in points
  • Prominence: 0 = auto; increase to skip broad shoulders
  • Center variation (±): how much a peak center may shift during fit
  • Max residual-add iterations: how many rounds of residual peak detection to run (0–20)
  • Reduce data points factor: 0 = no reduction; >1 speeds up fitting on large spectra
  • Fit method: leastsq (fast, default), least_squares (more robust), nelder
3 Fit range and baseline component New ▼

Fit range:

  • Use global x_ranges from sidebar — reuses the ranges from Processing Options
  • Otherwise, set a local left and right slider specific to this fit

Baseline component (optional):

  • Constant — adds a constant offset to the model
  • Linear — adds a linear trend
  • Polynomial — adds a polynomial of degree 1–10
💡 Tip: Use a baseline component only if the preprocessing baseline did not fully remove the background in the fitted region. Otherwise, leave it off — fewer parameters fit better.
4 Apply Fit New ▼

Click "🚀 Apply Fit" to run the fit on the selected spectrum only.

  • A progress bar shows residual-add iterations
  • Result is stored in session state and displayed below
  • Clear Result removes the stored result without changing parameters
⚠️ Note: Changing the spectrum or data mode after fitting keeps the old result visible with a notice. Press Apply Fit again to recompute, or Clear Result to reset.
5 Interpret results New ▼

The results panel shows:

  • Plot: data, total fit (dashed red), individual components, baseline component (dotted gray), residuals panel below
  • Component parameters table:
    • Center (± error) — peak position in X units
    • Height (± error) — peak maximum
    • FWHM (± error) — full width at half maximum
    • Area (± error) — integrated intensity (amplitude)
    • Sigma — Gaussian width
    • Gamma — Lorentzian width
    • Lorentz_frac — fraction of Lorentzian character (Voigt only)
  • Quality metrics: Reduced χ², χ², R², AIC, BIC, N points, number of varying parameters, DOF, fit range
  • Fit log: full lmfit report in expander (if Verbose is enabled)
💡 Tip: If reduced χ² does not decrease when adding more components, the extra components are likely fitting noise. Lower Max residual-add iterations or raise Minimum peak height.
6 Export New ▼

Two export buttons:

  • 📥 Download Components (CSV) — table of all components with parameters and errors
  • 📥 Download Fit Plot (PNG, 600 dpi) — publication-ready figure
💡 Note: Each export includes a timestamp in the filename for version tracking.
⚠️ Requires: lmfit (install via pip install lmfit).

7. Advanced Peak Analysis

Advanced

Automatically detect and characterize peaks within a user‑selected X‑range. This module provides quantitative data for each peak, across all selected spectra.

1 Enable Peak Analysis Advanced ▼

In the sidebar, under "Peak Analysis", check "Enable advanced peak analysis".

  • Peak width: Sets the number of points used for area calculation
  • Default: 20 points
  • Adjust based on your peak width
2 Select Analysis Range Advanced ▼

In the "Advanced Peak Analysis" tab:

  • Use the left and right sliders to define the analysis window
  • The shaded region on the preview plot shows your selection
  • Click "Analyze" to run peak detection
💡 Tip: Start with a wide range, then refine the boundaries to focus on specific peaks.
3 Review Results Advanced ▼

The analysis table displays:

  • Spectrum: Name of the spectrum
  • Peak position: X‑value at the peak maximum
  • Intensity: Peak height (maximum Y‑value)
  • Area: Integral under the peak
  • FWHM: Full Width at Half Maximum
  • Include: Checkbox to include/exclude the peak
💡 Note: Use the Include checkboxes to select which peaks to visualize and include in correlation analysis.
4 Export Results Advanced ▼

Export peak data for further analysis:

  • Click "Download peak analysis as CSV"
  • Includes all peaks with their calculated parameters
  • Respects the Include checkbox state
💡 Tip: For full peak decomposition with Voigt profiles, use the Voigt Fitting tab (Section 6) — it gives fit errors and a complete fit report.

8. Parameter Correlation

Advanced

Correlate spectral features (Intensity, Area, Position, FWHM) with experimental parameters such as temperature, concentration, or sample number.

1 Enable Correlation Advanced ▼

In the sidebar, under "Parameter Correlation", check "Enable correlation analysis".

  • Enter a numeric value for each spectrum
  • Provide a Parameter label (e.g., "Temperature (°C)", "Concentration (x)")
2 Run Peak Analysis First Advanced ▼

Correlation requires peak data:

  • First run Peak Analysis (Section 7)
  • Check the peaks you want to include
  • Correlation uses the most intense included peak from each spectrum
⚠️ Important: Correlation analysis requires at least 3 data points (spectra) for meaningful statistics.
3 Interpret Results Advanced ▼

Correlation tab displays:

  • 4 scatter plots: Parameter vs Intensity, Area, Position, FWHM
  • Pearson correlation coefficient (r): Shows the strength of linear relationship
  • Interpretation:
    • |r| > 0.7: Strong correlation
    • 0.4 < |r| < 0.7: Moderate correlation
    • |r| < 0.4: Weak correlation
💡 Tip: Positive r indicates a direct relationship; negative r indicates an inverse relationship.

9. Compare Two Spectra

Advanced

Compare two spectra side‑by‑side with difference analysis. Visualizes differences using heatmap color coding.

1 Select Spectra Advanced ▼

In the "Compare Two Spectra" tab:

  • Reference Spectrum: The baseline spectrum for comparison
  • Sample Spectrum: The spectrum to compare against the reference
  • Swap direction: Toggle between Sample - Reference and Reference - Sample
2 Configure Difference Plot Advanced ▼

Customize the difference visualization:

  • Color palette: Choose a diverging colormap (RdBu, Cool-Warm, Seismic, etc.)
  • Smoothing: Apply Gaussian smoothing to reduce noise
  • Symmetric scale: Center the color scale at zero
  • Significance threshold: Highlight regions where |difference| exceeds the threshold
3 Interpret Results Advanced ▼

Two‑panel display shows:

  • Top: Both spectra overlaid for visual comparison
  • Bottom: Difference profile with color‑coded heatmap

Statistics provided:

  • Mean Difference: Average deviation
  • Max |Difference|: Largest absolute deviation
  • RMS Difference: Root Mean Square deviation
  • Spectral Correlation: Pearson correlation between the two spectra
💡 Note: Red regions indicate positive difference (sample higher), blue regions indicate negative difference (sample lower).

10. Heatmap Generation

Advanced

Visualize spectral evolution as a function of a parameter (temperature, concentration, time, etc.). Heatmaps reveal patterns across the entire spectral range.

1 Assign Parameter Values Advanced ▼

In the "Heatmaps" tab:

  • Select Parameter type (Temperature, Concentration, or Custom)
  • Enter a numeric value for each spectrum
  • Check "Assign as the file name" to automatically extract numbers from filenames
💡 Tip: Name your files like 0.05.txt, 100.txt, or temp_25.txt and use the auto‑extract feature!
2 Configure Heatmap Settings Advanced ▼

Choose heatmap appearance:

  • Interpolation: Gaussian (smooth), Bilinear, Bicubic, Spline16, Lanczos, or None
  • Color palette: Viridis, Plasma, Inferno, Spectral, Cool‑Warm, Jet, etc.
  • Click "Apply for heatmaps" to generate
💡 Note: Gaussian interpolation provides the smoothest appearance; Bilinear is faster but less smooth.
3 View Heatmaps Advanced ▼

Two heatmaps are generated:

  • Intensity Heatmap: Raw intensity values (log‑scaled automatically if range > 100×)
  • Normalized Heatmap: Normalized intensity values (log‑scaled)

Features:

  • X‑axis: Raman shift (cm⁻¹)
  • Y‑axis: Parameter value (temperature, concentration, etc.)
  • Color: Intensity values with min/max displayed on colorbar
  • Automatic sorting: Values are sorted in ascending order
💡 Tip: Use heatmaps to identify intensity changes, peak shifts, or new peak emergence as a function of your parameter.

13. Troubleshooting

Help

Common issues and their solutions. If you encounter a problem, check here first.

Issue Possible Cause Solution
No spectra appear Files not selected or incorrectly formatted Check file format (2 columns, tab‑separated). Ensure spectra are selected in sidebar.
Peak analysis finds no peaks Range too narrow or peaks below detection threshold Widen the analysis range or adjust peak width parameter.
Heatmap shows no data Values not assigned or "Apply" not clicked Assign parameter values in the Heatmaps tab and click "Apply for heatmaps".
Normalized spectra look identical All spectra have same maximum intensity Try "Peak intensity (range)" or "Maximum rest intensity" normalization.
File uploader not clearing Session state not fully reset Click "Remove all spectra" button in sidebar. Files will be cleared.
Correlation shows NaN Insufficient data points or no peaks included Need at least 3 spectra with included peaks. Check peak analysis results.
Markers not showing "Show X values" or "Show preview" disabled Enable "Show X values on plot" and "Show preview line/region" in Spectral Markers tab.
Plots not updating Browser cache or session state issue Refresh the page (F5). Settings are preserved in session state.
Baseline correction removes real peaks lambda too high or p too low Lower lambda by 10× and/or increase p (try 1e-1). Use the Raman preset as a starting point. Enable "Show removed baseline" to verify.
Baseline correction leaves residual background lambda too low or p too high Increase lambda by 10× and/or lower p (try 1e-3). Consider the Aggressive preset.
Denoise distorts peak shapes Window or sigma too large Reduce window_length (SavGol) or sigma (Gaussian). Prefer SavGol with polyorder 2–3 and window 7–11.
Voigt fit finds too many components Min height too low or iterations too high Increase Minimum peak height, reduce Max residual-add iterations (try 1–2), or enable a baseline component.
Voigt fit finds too few components Threshold too high or peaks below threshold Lower Peak detection threshold, lower Minimum peak height, increase Max iterations.
Voigt fit does not converge / very slow Too many peaks, noisy data, or too many points Set Reduce data points factor (e.g., 2–5), use least_squares, reduce Max iterations, or narrow the fit range.
ModuleNotFoundError: pybaselines / lmfit Dependencies not installed Run pip install pybaselines lmfit and restart Streamlit.
Voigt Fitting tab shows old result Result belongs to a different spectrum or mode Click Clear Result or press Apply Fit again after switching spectrum/mode.
💡 General Tips Help ▼
  • Start simple: Begin with 2‑3 spectra to understand the workflow
  • Preprocessing first: Enable baseline correction before fitting Voigt profiles — the fit will be far more reliable
  • Use naming conventions: Name files with numeric values for auto‑extraction in heatmaps and 3D graphs
  • Save frequently: Export your data and plots regularly
  • Check logs: Error messages appear in the interface when something goes wrong
  • Reset if stuck: Use "Remove all spectra" to start fresh
  • Diagnose baseline: Enable "Show removed baseline" to verify the baseline does not eat real peaks
